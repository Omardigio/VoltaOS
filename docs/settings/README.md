# Settings

They open from the **car button** at the bottom left of the dock. At the top there is **Search settings**:
type a word ("tolls", "bluetooth", "equalizer") and go straight to the entry.

The pages, in the order of the side menu:

| Page | Contents |
|---|---|
| [Display and Lights](display-lights.md) | theme, driving position, brightness, blue light, screen cleaning, ambient lights |
| [Audio](audio.md) | resume on startup, output/input, equalizer, balance |
| [Navigation](navigation.md) | full screen, tolls and ferries, map view, GPS, voice |
| [Network and Bluetooth](bluetooth-network.md) | Wi-Fi, device pairing |
| [Apps and Arcade](apps-arcade.md) | hide apps, choose games and their covers |
| [CarPlay / Android Auto](carplay-android-auto.md) | theme, fit, resolution, DPI |
| [System](system.md) | 3D car, performance, language, connected services, keyboard, debug |
| [Updates](updates.md) | look for a new version and install it with one click |

Changes apply immediately and are saved automatically.
